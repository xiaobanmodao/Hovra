# 侧向手部几何优化设计

日期：2026-08-05

## 目标

修复侧向捏合时骨骼画面已经显示拇指和食指接触、距离数值却仍可能达到 `0.7+` 的问题，使画面骨骼、实时数值、校准样本和点击识别使用含义一致的几何特征，并记录足够数据支持下一阶段的视角自适应融合。

## 已确认根因

当前骨骼覆盖层只使用归一化图像坐标的 `x/y` 绘制，而 `landmarkDistance` 会同时使用 `x/y/z`。因此覆盖层显示的是二维重合，诊断和图像捏合比例却可能被不稳定的图像 `z` 拉大。归一化图像的 `x` 与 `y` 又分别以画面宽度和高度为单位，当前直接混合会产生宽高比误差。

当前图像手掌尺度为掌宽和掌长的平均值。侧掌时投影掌宽收缩，分母变小，捏合比例再次被放大。世界坐标虽然是三维坐标，但侧向遮挡下仍可能稳定地给出错误关键点；现有质量模型只能发现跳变和抖动，无法发现“稳定但错误”的侧向估计。

## 本轮范围

本轮实现几何根因修复和诊断基础，不直接训练新模型，也不在缺少真实侧向样本时重写最终概率权重：

1. 严格分离二维画面几何与三维世界几何。
2. 对画面 `x/y` 做宽高比修正，使数值与 Canvas 像素距离一致。
3. 画面手掌尺度使用 `max(掌宽, 掌长)`，避免侧掌掌宽塌缩拖低分母。
4. 图像深度保留为独立特征，不再混入二维指尖距离或二维手掌尺度。
5. 增加画面指尖间隙、画面宽高比、世界手掌尺度和手掌朝向诊断。
6. 升级本地诊断记录格式，使侧向数据可以可靠回放。
7. 因图像特征定义改变，升级个人点击校准存储版本，自动忽略旧配置。

## 几何模型

### 图像空间

新增 `buildImageHandGeometry(landmarks, aspectRatio)`：

- 将每个点变换为 `{ x: normalizedX * aspectRatio, y: normalizedY, z: 0 }`。
- 只在二维平面计算骨骼长度、手掌轴和指尖距离。
- `scale = max(distance2D(indexMcp, pinkyMcp), distance2D(wrist, middleMcp))`。
- 保存原始图像 `z`，单独计算 `imageDepthGap`；其数值不参与二维距离。
- 保存未归一化的 `screenTipGap`，用于诊断“指尖本身远”还是“尺度异常”。

宽高比采用 `videoWidth / videoHeight`。无有效视频尺寸的测试或旧回放使用 `1`，但实时摄像头每帧必须传入真实比例。

### 世界空间

保留现有三维 `buildHandGeometry` 作为世界几何：

- 使用 `x/y/z` 米制距离。
- 使用三维掌宽与掌长的平均值归一化。
- 从掌面法向量与摄像头 `z` 轴的夹角计算 `palmFacingScore = abs(zAxis.z)`；接近 `1` 表示正面，接近 `0` 表示侧向。

图像几何和世界几何必须拥有不同的构造函数，避免以后再次把坐标含义混用。

## 数据流

摄像头帧提供实际宽高比，`App` 将它与图像、世界关键点一起传给 `GestureEngine`。引擎分别构造二维图像几何和三维世界几何：

- 光标继续使用原始归一化图像点，不使用宽高比变换后的点。
- 点击特征的 `imageRatio` 改为二维、宽高比修正后的值。
- `worldRatio` 保持三维世界含义。
- `imageDepthGap` 使用原始图像 `z` 单独归一化。
- 诊断输出新增 `screenPinchGap`、`imageAspectRatio`、`worldPalmScale`、`palmFacingScore`。

## 诊断与界面

校准面板中的“捏合距离”改为“画面捏合比例”，直接显示点击引擎实际使用的二维比值。手势诊断增加：

- 二维指尖间隙
- 画面宽高比
- 画面手掌尺度
- 世界手掌尺度
- 手掌朝向：正面、斜向或侧向，并显示分数

现有世界捏合比例和图像深度仍保留，用户可以明确看到阻断来自哪个空间。

## 诊断记录兼容

诊断记录升级到版本 4。每帧特征新增上述四个数值。解析器继续接受版本 1、2、3，并为旧数据填入安全默认值；新写出的记录只使用版本 4。回放必须把记录的 `imageAspectRatio` 传回引擎，保证离线结果与实时结果一致。

## 个人校准兼容

由于 `imageRatio` 从混合 `x/y/z` 改为严格二维且尺度公式变化，旧边界不可继续使用。存储键升级为 `gesture-control.pinch-calibration.v2`，配置版本升级为 `2`。旧版本数据不删除，只是不再加载；用户重新校准后保存新版本。

## 错误处理

- 非有限或小于等于零的宽高比回退为 `1`。
- 图像关键点缺失或退化时继续返回无手状态。
- 世界关键点缺失时诊断显示不可用，现有二维降级路径继续工作。
- 新增诊断值必须经过有限数校验，异常记录不能写入或回放。

## 测试与验收

自动测试必须覆盖：

- 两个指尖 `x/y` 重合但 `z` 相差很大时，二维捏合距离仍接近零，图像深度差保持较大。
- 相同像素几何在 16:9 与 4:3 归一化坐标下得到相同结果。
- 掌宽投影压缩到 20% 时，使用掌长保护的侧向捏合比例不再被成倍放大。
- 世界三维距离仍对 `z` 分离敏感。
- 光标仍返回原始归一化图像坐标。
- 版本 1–3 诊断记录可以解析，版本 4 可以保存并确定性回放。
- 旧个人校准不会加载，新版本可以保存和解析。
- 中文界面准确显示二维、世界、深度和视角诊断。

现场验收步骤：正面、45°、接近 90°各完成五次真实捏合。侧向时若骨骼显示两指接触，二维指尖间隙和画面捏合比例必须同步下降；若仍被阻断，诊断记录必须明确显示是世界距离、深度还是姿态导致。

## 非目标

本轮不放宽点击阈值到 `0.7`，不替换 MediaPipe，不训练自定义分类器，不删除用户旧数据，也不在没有真实侧向样本的情况下修改最终概率融合权重。
