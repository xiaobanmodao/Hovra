# 全局手势控制与圆形光标设计

## 目标

桌面端启用系统控制后，用户可切换到任意 macOS 应用，继续以手势移动、点击和拖动系统鼠标。圆形虚拟光标始终显示在系统鼠标位置，作为跨应用操作的视觉定位提示。

## 行为

- “Enable system control” 是唯一的启用入口；启用后状态持续有效。
- 切换窗口、点击其他应用、完成短捏合点击或结束拖动都不得暂停系统控制。
- 用户点击 “Pause system control”、手部丢失、张开手掌、摄像头不可用、渲染器崩溃或应用退出时，必须停止控制；若已按下鼠标，必须先释放。
- 光标指示器为无边框、透明、置顶、鼠标穿透且不可聚焦的 Electron 覆盖窗口。它仅显示圆形指示器，不接收键盘或鼠标输入，不改变前台应用。
- 主窗口在接收手部坐标时，继续通过安全 IPC 将归一化坐标发送至主进程。主进程把坐标映射到主显示器的真实像素，并同时更新系统鼠标和覆盖圆的位置。
- 覆盖圆的可视状态反映手势状态：追踪时正常、捏合/拖动时强调、暂停或丢失时隐藏。

## 架构

1. 主进程拥有可点击的控制主窗口和不可交互的 `cursorOverlay` 窗口。
2. 覆盖窗口加载极简本地渲染页面，使用受限 preload 接收固定 IPC 通道的光标状态；不暴露 Node 能力。
3. 鼠标控制器继续是所有系统鼠标事件的唯一出口；主进程新增覆盖层更新接口，避免渲染器直接创建窗口或控制系统鼠标。
4. 现有 `blur` 生命周期从“暂停控制”改为“不改变会话”。应用退出、主窗口销毁、渲染器导航/崩溃仍保留安全释放。

## 异常与安全

- 无 Accessibility 权限时，系统控制和覆盖层均不启用。
- 覆盖窗口销毁时可按需重新创建，但不得让覆盖窗口获得焦点。
- 覆盖层坐标必须限制在主显示器范围内；无效坐标隐藏覆盖圆并不发出系统鼠标事件。
- 控制开关只由显式启用/暂停及不可恢复的安全事件改变；普通窗口焦点变更和手势点击不改变开关。

## 验收与测试

- 单元测试覆盖：失焦不暂停、点击后会话仍有效、显式暂停会释放按键、覆盖层只接收主进程的固定状态消息、坐标映射与可视状态。
- 集成测试覆盖：启用后切换到另一个应用，圆形指示器持续跟随手势；短捏合可点击目标；长捏合可拖动；点击后仍保持 Enabled；点击暂停后圆形隐藏且后续动作无效。
