# 稳定手势内核重建设计

## 背景与根因

当前实时点击链路已经叠加了 MediaPipe 图像坐标、MediaPipe 世界坐标、时序特征、质量评分、概率估计、个人校准、视角判断和 Apple Vision 异步融合。实际摄像头中，这些数据并非同一时间采集，世界坐标在遮挡和侧手姿态下也会跳变。结果是：

- Apple Vision 低频异步结果会与后续 MediaPipe 帧配对，产生错帧判定；
- 双模型 3/5 投票、释放投票和 80ms 原生采样间隔叠加，点击反馈明显变慢；
- 图像几何主动丢弃了 MediaPipe 的 `z`，而世界坐标在指尖遮挡时不稳定，真实接触会被算成很远；
- 个人校准同时依赖三个不同分布的通道，用户很难稳定采到所谓“分度足够”的样本；
- 张掌和点击分别经过不同的状态机，冲突时会互相覆盖；
- 合成测试主要验证了人为构造的数据，没有覆盖真实摄像头的遮挡、抖动和错帧。

这不是继续调整一个阈值能解决的问题，需要把实时控制恢复为单一、可解释、可回放的状态机。

## 目标

1. 实时功能只保留光标移动、拇指与食指点击、张开手掌暂停。
2. 点击后系统控制保持开启，只有用户主动关闭或安全生命周期事件才能关闭。
3. 捏合闭合后快速触发一次点击，持续捏合不重复点击，必须明确松开后才能再次点击。
4. 屏幕投影中拇指和食指重合、但纵深仍分离时不得点击。
5. 握拳不得判为张掌；张掌进入和退出均需短暂连续帧确认。
6. 默认实时路径不再调用 Apple Vision，不依赖世界坐标、概率模型或个人校准。
7. 保留中文、可理解的实时诊断，让问题可以用记录而不是主观描述复现。

## 方案选择

### 方案 A：继续调双模型阈值

改动最小，但无法消除异步错帧和单目模型共同存在的深度歧义；继续调参会在“难触发”和“误触发”之间反复。放弃。

### 方案 B：训练个人分类模型

长期潜力最高，但需要大量带标签的真实视频、不同光照/角度/左右手覆盖和持续评估，不适合作为本轮稳定性修复。后续可作为影子模型研究。

### 方案 C：恢复单模型稳定内核（采用）

让 MediaPipe 每个新视频帧同步完成全部实时决策。采用最初版本已验证好用的直接几何思路，同时只加入两项必要保护：尺度自适应的双阈值，以及 MediaPipe 归一化关键点自带 `z` 的纵深重叠保护。该方案延迟最低、状态最少、每次判定都能解释和回放。

## 实时识别设计

### 输入

- 仅使用同一 MediaPipe 推理结果中的 21 个归一化关键点；
- 光标使用食指指尖；
- 点击几何只使用拇指指尖、食指指尖和掌部尺度；
- 世界关键点可继续由模型返回，但不参与实时控制。

### 捏合度量

每帧计算：

- 画面距离：经过视频宽高比修正的拇指—食指二维距离；
- 纵深距离：同一组 MediaPipe 归一化关键点的 `z` 差；
- 空间距离：画面距离与纵深距离的三维合成；
- 掌部尺度：腕部到中指掌指关节长度与食指/小指掌指关节跨度的稳健组合。

阈值随掌部尺度小幅自适应，并限制在最初版本有效的绝对范围内。这样既保留最初固定阈值的稳定性，又避免手靠近或远离摄像头时完全失效。

进入阈值严格、退出阈值宽松，形成滞回区间。屏幕距离很小但 `z` 差明显时标记为“纵深重叠”，阻止点击。

### 点击状态机

- `neutral`：等待接触；
- `candidate`：连续接触确认；
- `active`：确认后的第一帧立即产生一次点击；
- `releasing`：等待连续分离；
- 回到 `neutral` 后才能产生下一次点击。

默认需要两个连续接触帧，目标确认延迟不超过 90ms；需要两个连续分离帧重新武装。单帧抖动不会触发或重复点击。

### 张掌状态机

食指、中指、无名指和小指均需同时满足：

- 指尖比近端关节明显更远离手腕；
- 指根到指尖的直线距离与关节路径长度之比足够高；
- 指尖伸展距离达到相对掌部尺度要求。

连续三帧才进入暂停，连续两帧非张掌才退出。握拳、半握拳和单指伸出均不能进入暂停。张掌优先级高于点击，并会清空未完成的点击候选，但不会关闭系统控制开关。

### 光标与性能

- 去掉实时链路中的全手自适应滤波和 Apple Vision JPEG 编码/IPC；
- 每个新视频帧运行一次 MediaPipe，不额外限频；
- 只对最终食指光标做轻量指数平滑，默认平滑系数提高以降低拖尾；
- 摄像头丢帧时进入 `lost`，不产生点击，恢复后重新确认。

## 界面与诊断

- 移除会影响实时判定的个人点击校准入口；旧的本地校准数据不再读取；
- 校准区只保留点击灵敏度、光标平滑和光标偏移；
- 诊断显示空间捏合比例、画面比例、纵深比例、接触/释放阈值、连续确认帧和阻止原因；
- 骨骼图只绘制实际控制所用的 MediaPipe 结果，避免双骨骼误导；
- 保留轨迹导出能力，并升级格式以记录稳定内核的判定证据。

## 验证标准

- 真捏合：连续两帧内只触发一次点击；
- 持续捏合：任意时长不重复点击；
- 松开后再次捏合：能产生第二次点击；
- 投影重合但 `z` 分离：零点击；
- 握拳、半握拳、单指伸出：均不暂停；
- 真张掌：三帧进入暂停，两帧退出；
- 单帧噪声、短暂丢手、乱序时间戳：零误点击；
- 识别路径不调用 Apple Vision；
- 完整单元测试、类型检查、Web 构建、Electron 打包与 macOS 签名检查全部通过。

## 边界

普通单目摄像头不可能获得物理级精确深度。本设计利用同一模型的相对 `z` 和严格状态机显著减少纵深重叠误触，但不会宣称在所有极端遮挡下达到零错误。后续若需要进一步提高上限，应采集真实匿名轨迹并离线训练时序分类器，而不是再次把多个异步单目模型直接串入鼠标控制。
