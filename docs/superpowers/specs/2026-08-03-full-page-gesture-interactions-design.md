# 全页手势交互：设计规格

## 目标

将网页演示中的点击目标和拖拽卡片从局部演示区提升为全页浮动交互元素。用户可以通过虚拟手势光标在整个可视页面范围内点击目标、拖动卡片，同时始终让两个元素保持可见、可再次操作。

## 范围

- 点击目标与拖拽卡片使用浏览器视口坐标和 `position: fixed` 布局。
- 短捏合在点击目标的当前矩形范围内时增加点击计数。
- 长捏合从卡片上开始，卡片可移动至当前视口的任意安全位置。
- 卡片和点击目标均保留固定安全边距；窗口缩小时自动夹紧回可视区域。
- 虚拟光标保持页面最上层且不拦截页面事件。
- 手掌张开、手部丢失和摄像头帧停滞会结束活动拖拽并保留最后的安全位置。

## 不在范围内

- 触发页面任意原生链接、按钮或表单。
- 操作浏览器或系统鼠标。
- 多个可配置对象的注册框架。

## 架构

现有 `Playground` 改为全页交互层，继续接收 `cursor` 和 `GestureOutput`。它分别管理点击目标和卡片的视口位置，并以 `getBoundingClientRect()` 判断命中。位置工具函数集中处理安全边距与视口夹紧；窗口 `resize` 时通过同一逻辑修正两个元素。

## 交互规则

- 点击：仅在 `output.click` 为真且虚拟光标位于点击目标内时计数一次。
- 拖拽开始：仅当 `output.dragStart` 为真且虚拟光标位于卡片内时开始，并保存光标相对卡片左上角的偏移。
- 拖拽中：只有 `output.state === "dragging"` 且存在已保存偏移时更新卡片位置。
- 拖拽结束：收到 `dragEnd` 时清除偏移。暂停、丢手和帧停滞沿用现有状态机产生的 `dragEnd`。
- 夹紧：元素的左上角不得小于安全边距，右下角不得超过视口减安全边距；当视口小于元素尺寸加边距时，位置为零。

## 测试与验收

- 虚拟光标能在页面任意位置命中点击目标；目标外点击不计数。
- 卡片能拖至四个方向边界，并保持完整可见。
- 调整浏览器窗口后，点击目标和卡片保持在可视区域。
- 点击、拖拽、暂停与丢手结束拖拽的既有行为不互相干扰。
- 自动化测试覆盖命中、边界、缩放夹紧与拖拽结束；在桌面 Chrome 或 Edge 中手动验证全页运动。
