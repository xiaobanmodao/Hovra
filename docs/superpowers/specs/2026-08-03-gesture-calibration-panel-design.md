# 手势校准面板：设计规格

## 目标

为网页演示加入可观察、可调节的临时校准面板，使真实摄像头测试能够区分识别、阈值和光标平滑问题，并将验证有效的参数固化为项目默认值。

## 范围

- 默认展开、可折叠的校准面板。
- 显示实时捏合距离、捏合阈值、手势状态、平滑后光标坐标、平滑系数和拖拽保持时长。
- 提供捏合阈值、平滑系数、拖拽保持时长的步进调节，以及恢复默认值按钮。
- 参数只保留在 React 内存；刷新页面即恢复配置文件中的默认值，不使用存储、后端或上传。
- 在 Edge 中按移动、短捏合、长捏合拖拽、张开手掌暂停四组动作验证；根据结果将确认的默认值写回 `src/gesture/config.ts`。

## 不在范围内

- 自动化个人校准向导。
- 跨页面保存的个人偏好。
- 系统鼠标控制或桌面封装。

## 架构

`App` 保存本会话的 `GestureSettings` 状态，并把它传给 `GestureEngine` 和 `CalibrationPanel`。手势引擎不再直接导入可调常量，而是接收完整设置，保持纯函数测试能力。面板只编辑设置并显示诊断值；它不访问摄像头、MediaPipe 或任何持久化 API。

## 交互规则

- 折叠后仍保留校准效果，只有面板内容隐藏。
- 捏合阈值步进 `0.005`，范围 `0.025–0.100`。
- 平滑系数步进 `0.05`，范围 `0.05–1.00`。
- 拖拽保持时长步进 `50ms`，范围 `150–1000ms`。
- 恢复默认值使用 `config.ts` 导出的原始默认设置。
- 捏合距离只在手被追踪且食指/拇指关键点存在时显示；其余状态显示 `—`。

## 测试与验收

- 校准面板显示默认参数、实时状态、坐标与捏合距离。
- 每个控制的步进、上下边界、折叠和恢复默认值都有单元测试。
- 手势引擎在非默认设置下仍能分别触发点击和拖拽。
- Edge 实测时，用户能够将光标移动、短捏合点击、长捏合拖拽，并用张开手掌暂停控制。
- 实测后在规格记录最终默认参数与观察到的体验。
