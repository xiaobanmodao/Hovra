# Hovra 稳定右键恢复设计

## 目标

在不降低现有光标移动、左键短按、左键长按拖动和张掌停止稳定性的前提下，恢复全局右键点击。右键使用“拇指与中指短捏合”，只在严格确认释放后触发一次。

## 选择的方案

采用“稳定空间几何 + 独立短按状态机 + 全局动作锁”。

不恢复旧版“多个指尖中距离最短者获胜”的单帧分类，因为它会在手掌旋转、指尖交叉和关键点抖动时造成左键/右键串扰。也不引入新的机器学习模型，因为当前没有足够的已标注右键数据，额外模型会增加延迟而无法提供可验证的防误触收益。

## 右键几何证据

`measureStableHand` 在现有宽高比修正坐标系中，同时计算拇指到中指的：

- 二维画面距离与掌部尺度之比；
- MediaPipe 归一化纵深差与掌部尺度之比；
- 二维和纵深合成的空间距离比。

右键接触必须同时满足：

1. 拇指和中指都具有有限的纵深数据；
2. 拇指—中指空间距离比不大于当前接触阈值；
3. 拇指—食指空间距离比不小于当前释放阈值；
4. 拇指—无名指空间距离比不小于当前释放阈值。

第三、四项是动作排他门，避免左键手势、相邻指尖交叉或未来双击手势被判成右键。右键释放使用与左键相同的迟滞释放阈值。二维重合但纵深分离必须标记为 `depth` 阻断，不得降级成二维判断。

## 右键时序

复用 `PinchClickStateMachine` 的速度、移动范围、连续接触、连续释放、追踪间隔、抑制冷却和重新武装逻辑，并给配置增加 `holdEnabled`：

- 左键保持 `holdEnabled: true` 和 420 毫秒长按阈值，行为不变；
- 右键使用 `holdEnabled: false`、至少 3 帧连续接触、2 帧连续释放和 650 毫秒最长接触时间；
- 当禁用长按的状态机达到最长接触时间时，以 `timeout` 取消当前动作，不发出点击、长按开始或拖动事件；
- 取消后必须先完成释放与干净帧冷却才能重新武装。

## 动作互斥

`GestureEngine` 持有 `"left" | "right" | null` 动作锁。

- 无锁时，严格右键接触优先建立右键锁；否则现有左键接触建立左键锁。
- 锁定期间只把真实接触证据送给对应状态机，另一状态机收到抑制证据，不能并行积累票数。
- 候选失败、短按完成、超时取消、拖动释放、张掌、追踪不安全、丢手或时间戳异常时释放动作锁。
- 含糊帧不建立动作锁；不会从一个已开始的动作中途切换为另一个动作。

张掌仍具有最高优先级。进入张掌暂停时两个捏合状态机都重置；左键拖动若正在进行仍发出一次安全 `dragEnd`，右键永远不产生鼠标按下状态。

## 输出与桌面分发

右键候选/激活/释放阶段输出：

- `state: "right-pinching"`；
- `candidate` 或 `lockedGesture: "right"`；
- `confirmationProgress` 使用右键连续接触票数；
- `longPressProgress: 0`；
- 释放完成帧只产生一次 `rightClick: true`，并通过现有 `clickCursor` 锁定动作开始前的系统坐标。

React 分发层在右键脉冲时先把系统指针移到锁定坐标，再调用已有 `desktopBridge.rightClick()`。点击完成不会关闭系统控制开关。Electron preload、IPC、MouseController、RobotJS 和紫色圆形覆盖层接口已经存在，只复用并验证，不新增 IPC 通道。

浏览器测试区增加“右键次数”，并把操作提示更新为“拇指 + 中指：右键”。这只是页面内识别反馈，不尝试伪造浏览器原生上下文菜单。

## 诊断与轨迹

现有 `GestureTraceV5.features.rightPinchRatio` 和 `TraceGestureEvent.rightClick` 已经存在，因此不升级轨迹版本。诊断面板的“右键捏合比例”改为真实空间距离；轨迹记录右键比例、候选、锁定和释放事件。旧版 v1–v5 轨迹解析保持兼容。

## 自动回归

扩展语义回归事件类型以包含 `rightClick`，并让所有无动作场景也把意外右键视为失败。固定矩阵新增：

- 合法右键短捏合，只允许一次 `rightClick`；
- 右键持续超过 650 毫秒，不允许右键、左键或拖动；
- 拇指—中指二维重合但纵深分离，不允许任何操作；
- 左键短捏合不得产生右键；
- 同时接近多个指尖的含糊姿态不得产生任何操作。

单元测试还覆盖几何尺度/旋转不变性、缺失纵深、动作锁、张掌优先、丢手取消、右键锁定坐标、React 桥接及系统控制保持开启。

## 非目标

本阶段不恢复双击、滚动或其他快捷动作；不改变左键阈值、420 毫秒长按、光标热点、辅助功能权限或摄像头模型；不增加依赖、不上传数据。

## 验收标准

- 合法拇指—中指短捏合只在确认释放后产生一次右键。
- 保持右键捏合、二维重合但纵深分离、左键捏合、握拳、张掌和快速移动都不会产生意外右键。
- 左键短按与长按回归结果保持不变。
- 页面右键测试计数、紫色系统光标反馈和系统右键调用均可由自动测试证明。
- 专用轨迹回归、完整测试、Electron 类型检查和生产构建全部通过。
