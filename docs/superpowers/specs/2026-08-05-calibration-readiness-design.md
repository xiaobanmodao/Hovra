# 个人点击校准实时判定设计

日期：2026-08-05

## 目标

让用户在记录每个校准样本之前就知道动作是否合格、还需要调整什么，并让最终“区分度不足”能够指出具体失败维度。整个改动只提升校准采样质量，不修改手势控制引擎、已保存配置结构或隐私边界。

## 现状与根因

当前向导只判断摄像头是否提供了手部特征。一旦有特征，按钮立即可点，单帧数据会直接写入样本。最终拟合同时检查画面距离、三维距离和前后深度，每一项都要求接触与未接触边界至少相差 `0.06`；任意一项失败时，界面却只显示统一的“样本区分度不足”。因此用户既无法在记录前纠正动作，也无法在失败后知道问题来自哪一项。

## 方案比较

### 方案一：固定阈值提示

只根据当前一帧和固定阈值显示合格或不合格。实现简单，但容易把抖动、误检或偶然合格帧记入样本。

### 方案二：与拟合规则同源的稳定窗口（采用）

使用最近四帧判定动作持续合格，并根据当前校准阶段给出逐项反馈。未接触阶段的阈值由已经记录的接触样本动态推导，预留比最终 `0.06` 更大的安全间隔。它能在不改变现有流程的前提下显著降低坏样本概率。

### 方案三：自动捕获

姿势稳定后自动记录。操作更快，但用户难以控制采样时机，也容易在阶段切换时误采。此次保留手动按钮，只在系统确认“可以记录”时启用。

## 判定模型

新增纯函数判定器，输入当前阶段、最近样本窗口和已经记录的接触样本，输出状态、中文原因、逐项检查结果和稳定帧进度。

状态分为三类：

- `blocked`：当前动作不满足核心条件，按钮禁用，并给出明确调整方法。
- `stabilizing`：当前动作正确但持续时间不够，显示“保持姿势稳定 2/4”。
- `ready`：最近四帧全部满足条件且波动足够小，显示“可以记录”，按钮启用。

接触阶段允许比默认识别边界更宽、但仍能保证最终拟合安全的个人范围：

- 画面距离 `imageRatio <= 0.39`
- 三维距离 `worldRatio <= 0.45`
- 前后深度差 `depthGap <= 0.24`

其中画面距离上限经过最终固定分开边界反推：`0.39 × 1.08 = 0.4212`，与 `0.50` 仍有约 `0.079` 间隔，大于最终要求的 `0.06`。这样不会因默认识别阈值过严而阻止个性化校准。

未接触假重合阶段要求：

- 画面仍重合：`imageRatio <= min(0.50, 接触画面边界 + 0.08)`
- 三维距离分开：`worldRatio >= 接触三维边界 + 0.08`
- 前后深度分开：`depthGap >= 接触深度边界 + 0.08`

接触边界沿用最终拟合方式，即接触样本第 90 百分位乘以 `1.08`。这里使用 `0.08` 安全间隔，比最终必须达到的 `0.06` 多留 `0.02`，避免临界样本在最终拟合时失败。

四帧窗口还要求波动范围不超过：画面距离 `0.035`、三维距离 `0.05`、前后深度 `0.04`。每次成功记录后清空窗口，要求用户重新稳定动作，避免一个静止帧被连续记录多次。

## 界面反馈

手势示意图下增加实时判定卡片：

- 绿色：可以记录。
- 黄色：动作正确，继续保持，并显示稳定帧进度。
- 红色：不可记录，显示最优先的修正动作。

卡片内展示“画面距离、三维距离、前后深度、稳定帧”四项检查。没有检测到手时显示“把整只手放入画面”。接触动作不够紧时显示“让拇指和食指真正接触”；假重合画面未重合时显示“让两指尖在画面中重合”；三维或深度未拉开时显示“增加前后距离”。

按钮只有在 `ready` 状态可用。按钮点击后记录稳定窗口的中位样本，而不是偶然的最后一帧，以进一步降低噪声。

## 最终失败诊断

拟合函数新增结构化分析结果，分别报告 `image`、`world`、`depth` 的接触边界、分开边界、实际间隔、所需间隔和是否通过。失败时抛出带分析数据的专用 `TypeError` 子类，仍保持原有“overlap”错误语义兼容旧测试。

向导捕获该错误后，列出失败维度及针对性建议，例如：

- 画面距离不足：真实接触样本要更紧，假重合样本仍要保持画面重合。
- 三维距离不足：假重合时增加拇指与食指的实际空间距离。
- 前后深度不足：让两指沿摄像头前后方向分开更多。

## 数据流与边界

摄像头每次产生新手部特征时更新四帧窗口；纯判定器生成实时状态；向导只在状态为 `ready` 时记录窗口中位数；收集满 `5 + 5 + 3` 个样本后调用现有拟合流程。仍只保存距离和质量数值，不保存图片或视频。

## 测试策略

- 纯判定器：无手、接触未合格、稳定中、稳定合格、假重合画面不合格、空间/深度未分开、窗口抖动。
- 拟合诊断：精确指出失败维度，并保留成功与解析行为。
- 向导集成：按钮门控、四帧稳定、记录后重置、阶段切换、完成回调和中文错误提示。
- 回归验证：全量单元测试、TypeScript 构建、Electron 类型检查、桌面打包和打包应用现场检查。

## 非目标

本轮不增加新的控制手势，不改点击识别模型，不改个人配置存储版本，不做自动采样，也不保存摄像头画面。
