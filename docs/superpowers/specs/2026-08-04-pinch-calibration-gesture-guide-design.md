# 个人点击校准真人手图示设计

## 目标

让用户在不依赖长段文字的情况下，能准确模仿个人点击校准的四类动作，尤其明确点击只由拇指与食指完成，并区分“真实接触”和“画面重合但实际未接触”。

本次只增强校准引导界面，不修改采样数量、阶段切换、点击识别模型、阈值拟合或隐私策略。

## 已确认的视觉方向

采用用户确认的真人手教学图，不再使用骨架线框或抽象手掌。

四幅图统一使用深蓝背景、接近摄像头的观察角度、同一只手的左右方向和一致的真人手风格：

1. **自然移动**：完整张开的手掌正对摄像头，五指自然分开，青色箭头提示缓慢左右移动。
2. **正面真实点击**：标准 OK 手势结构，只有拇指与食指指腹接触并形成清晰圆环；中指、无名指和小拇指保持展开；接触点显示绿色提示。
3. **侧面真实点击**：手掌旋转约 90°，仍只有拇指与食指真实接触；绿色提示标记接触点。
4. **假重合样本**：正面画面中拇指和食指看似重合，实际前后分开约 2–3 厘米；侧视小窗和两指之间的红色分离标记解释距离。不得使用覆盖整幅图的大红叉，以免被误解成“不要执行这一校准步骤”。

图中不嵌入文字，避免图片文字模糊或本地化问题；中文标题、说明和计数由界面原生文本负责。

## 界面结构

校准向导顶部增加四步进度条，当前步骤高亮。内容区一次只展示当前步骤的大图，避免四幅图同时出现造成信息过载。

每个采样阶段从上到下包含：

1. 当前步骤编号和中文标题。
2. 对应真人手大图及准确的替代文本。
3. 一句主要动作提示。
4. 一句固定防错提示：真实点击步骤强调“只使用拇指和食指；其余三指不要弯曲参与”，假重合步骤强调“两指不要真实接触”。
5. 当前采集数量和原有记录按钮。

引导区在窄窗口下保持单列，图片完整显示且不裁切手指或接触点。完成和错误状态继续沿用现有反馈，不保留无关的动作图。

## 组件与资源

- 先修正获批原图的左右手方向和假重合标记，再裁切为四个独立 PNG，保存到 `src/assets/pinch-calibration/`。裁切后的四图必须通过五指数量、拇指—食指关系、接触状态和方向一致性检查。
- 新增一个只负责渲染图片、步骤标题和防错提示的轻量组件，避免把视觉映射继续堆进采样逻辑。
- `PinchCalibrationWizard` 根据现有 `stage` 选择对应步骤元数据，并把计数、按钮状态和记录回调继续交给现有采样步骤。
- 所有图片随 Electron 包本地打包，不依赖网络，也不保存或上传摄像头内容。

## 数据流

现有阶段状态保持不变：`intro → baseline → front → side → negative → complete/error`。

阶段值只用于读取静态视觉元数据：图片地址、标题、主要说明、警示说明和替代文本。用户点击记录按钮后，仍执行原有 `currentSample` 采集和计数逻辑；图示组件不读取摄像头数据，也不参与识别判断。

## 错误与可访问性

- 未检测到手部时继续禁用记录按钮并显示“请先把手完整放入画面”。
- 每幅图提供描述动作和接触关系的中文 `alt` 文本。
- 颜色只做辅助；所有绿色接触提示和红色错误提示都由文字重复说明。
- 图片使用固定宽高比，避免加载时界面跳动；打包资源若异常不可见，文字说明仍可独立指导操作。

## 测试与验收

自动测试覆盖：

- 进入基线、正面、侧面和假重合阶段时分别显示正确图示与中文说明。
- 正面和侧面步骤包含“只使用拇指和食指”的防错提示。
- 假重合步骤包含“实际不要接触”的提示。
- 加入图示后，原有 3 秒基线、5 次正面、5 次侧面、3 次假重合、完成、取消和无手禁用行为保持不变。
- 生产构建与 Electron 打包能够解析四个本地图片资源。

人工验收标准：用户无需阅读段落说明，即可从当前大图辨认手掌朝向、参与动作的两根手指、是否要求真实接触以及下一步需要采集的动作。
