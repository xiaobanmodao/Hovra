# 手势控制完整中文界面设计

## 目标

将网页演示和 Electron 桌面程序中用户能够看到或听到的英文内容全部替换为简体中文，让不阅读英文的用户可以完成摄像头启用、系统控制开关、手势校准、诊断查看、测试操作和追踪导出。

## 翻译范围

- 应用名称、主标题、说明文字和各区域标题。
- 摄像头、模型加载、手部检测、识别错误和画面停滞状态。
- 系统鼠标权限、启用、暂停、系统设置入口和操作说明。
- 校准面板的字段、按钮、折叠控制、单位和无障碍标签。
- 识别诊断的阶段、候选手势、锁定动作、确认进度、尺度、比例、滚动分数和质量。
- 点击目标、拖动卡片、右键/双击/滚动计数与手势提示。
- 本地追踪保存按钮、保存结果、保存对话框标题和文件类型名称。

## 动态状态映射

新增集中式中文显示映射，只负责显示，不改变识别引擎使用的内部值：

- 引擎状态：`lost`、`tracking`、`left-pinching`、`right-pinching`、`double-pinching`、`dragging`、`scrolling`、`paused`。
- 稳定阶段：`neutral`、`candidate`、`active`、`dragging`、`releasing`、`cooldown`、`lost`。
- 手势类型：`left`、`right`、`double`、`scroll`、`open-palm`。

内部 TypeScript 联合类型、IPC 通道、CSS 类名和追踪 JSON 字段继续使用英文，保证现有自动测试、回放文件和桌面协议兼容。

## 界面行为

- 产品标题显示为“手势控制”。
- 所有按钮使用明确中文动词，例如“启用系统控制”“暂停系统控制”“保存诊断记录”。
- 状态值不直接输出内部英文枚举，而是通过中文映射显示。
- 数值、小数精度、快捷操作和系统控制的显式开关逻辑保持不变。
- 浏览器演示仍不显示桌面追踪保存按钮；Electron 中继续由用户主动保存。

## 错误处理与兼容性

- 面向用户的错误信息改为中文。
- 底层异常文本可保留英文，因为它们不直接显示在正常界面中，并被测试用来验证安全边界。
- 不改动 MediaPipe、鼠标控制、手势阈值和打包配置。
- 布局沿用现有设计，必要时允许中文标签自动换行，避免文字被截断。

## 测试与验收

- 为动态状态映射编写单元测试。
- 更新组件和 App 测试，以中文可访问名称查询按钮与区域。
- 增加页面级断言，确保主要用户界面不再出现原英文标题、按钮或状态值。
- 运行全部测试、前端构建、Electron 类型检查和 arm64 打包。
- 启动最终打包程序，检查摄像头、系统控制、校准、诊断和测试区均显示中文，且系统控制默认暂停。
