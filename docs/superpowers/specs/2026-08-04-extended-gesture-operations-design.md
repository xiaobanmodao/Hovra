# 扩展手势操作与低延迟光标反馈设计

## 目标

在现有全局移动、左键和拖动能力上，完整增加右键、双击和滚动，并让圆形虚拟光标在手势被识别的第一帧就显示对应反馈。系统控制仍只由用户点击总开关启停；点击完成、切换应用、张开手掌或短暂丢失手部都不得关闭控制。

成功标准：

- 食指与拇指短捏合执行一次左键，长捏合继续进入拖动。
- 中指与拇指短捏合执行一次右键。
- 无名指与拇指短捏合直接执行一次系统双击，不等待第二个左键手势。
- 食指和中指伸出、无名指和小指弯曲时进入滚动模式；手部垂直位移产生平滑滚轮增量，系统光标不随之移动。
- 全局圆形光标能区分跟踪、左键捏合、右键捏合、双击捏合、拖动和滚动，并在识别状态改变后的下一次渲染/覆盖层更新中反馈。
- 所有新操作遵守现有权限、可信 IPC、动作队列、安全释放和显式总开关约束。

## 手势映射与优先级

每帧先计算拇指到食指、中指、无名指三个指尖的三维距离，再判断两指滚动姿势。分类优先级如下：

1. 已进入拖动时，仅食指捏合的保持与释放可以改变拖动状态，避免其他手指造成误操作。
2. 三个捏合候选中选择距离最短且低于阈值的一个；食指对应左键/拖动，中指对应右键，无名指对应双击。
3. 没有捏合时判断滚动姿势。
4. 张开手掌保持现有暂停姿势语义，只暂停当前手势识别，不关闭系统控制。
5. 其余有效手势为普通光标跟踪；无手部为丢失状态。

右键和双击只在对应捏合释放时触发，且不进入拖动。左键保持现有短按与长按分流，避免改变用户已经验证正常的拖动习惯。双击采用独立无名指捏合，而不使用“两次食指捏合”检测，因此单击不需要等待双击判定窗口。

滚动姿势使用指尖与近端关节的相对方向识别：食指、中指伸出，无名指、小指弯曲。进入滚动时记录手掌参考纵坐标；随后累计纵向位移，超过小阈值后输出整数滚轮步长并更新参考点。方向遵循 macOS 常规滚轮事件：手向上移动时内容向上滚动，手向下移动时内容向下滚动。离开姿势后清空累计值，重新进入不会跳动。

## 状态和输出模型

手势状态扩展为：

- `tracking`
- `left-pinching`
- `right-pinching`
- `double-pinching`
- `dragging`
- `scrolling`
- `paused`
- `lost`

输出事件扩展为左键、右键、双击、滚轮增量、拖动开始和拖动结束。事件仍是单帧脉冲；持续状态由 `state` 表达。为兼容现有测试界面，页面点击计数只消费左键事件，拖动演示只消费拖动事件。

## 数据流与组件边界

1. `GestureEngine` 只负责 landmark 分类、状态转换和离散事件，不依赖 React、Electron 或 RobotJS。
2. `App` 将识别输出映射到页面虚拟光标和桌面桥接调用。滚动状态不会更新系统光标坐标；其他活动状态沿用现有平滑和校准。
3. preload 为右键、双击、滚动和带视觉状态的移动暴露窄接口，并继续验证有限数值和归一化坐标。
4. Electron 主进程验证事件来源和载荷，将动作串行送入 `MouseController`。
5. `MouseController` 统一执行权限检查、会话开关、按键互斥、动作排队、原生光标刷新和覆盖层更新。
6. `systemMouseAdapter` 将动作映射为 RobotJS 左键、右键、双击和滚轮调用。
7. 覆盖层只负责绘制圆形光标；状态消息改变颜色、缩放和短脉冲动画，不接收鼠标事件，也不获得焦点。

## 低延迟反馈方案

当前延迟根因是覆盖层只接收 `tracking` 和 `dragging`，而点击布尔事件只在捏合释放时出现。因此修复位于状态传递链路，而不是缩短拖动阈值。

当第一帧识别到任一捏合时，渲染器立即把对应 `*-pinching` 状态随本帧坐标送到主进程，覆盖层在同一次移动更新中改变样式。松开时再执行实际系统点击，以保留短按与拖动的可靠区分；点击完成后触发一个不阻塞动作队列的短脉冲。这样视觉按下反馈不再等待 `dragHoldMs`，系统点击语义保持可靠。

滚动状态显示双环和方向性短动画。覆盖层状态更新失败不得阻止系统输入；下一帧会重试并恢复样式。

## 安全与异常处理

- 系统控制未显式启用、辅助功能权限丢失或 IPC 来源不可信时，所有动作都静默丢弃。
- 拖动期间忽略点击、右键、双击和滚动，直至左键安全释放。
- 手部丢失、摄像头停帧、渲染器退出或应用退出时，只释放可能按下的左键；除生命周期关闭外不擅自改变用户总开关。
- 非有限坐标、越界归一化坐标和非有限滚轮值在 preload 与主进程边界拒绝。
- 滚轮每帧增量设置上限，防止识别跳点造成页面瞬移。

## 测试与验收

- 手势引擎单元测试覆盖三个捏合的识别、最短距离优先级、左键长按拖动、释放事件、滚动进入/累计/方向/退出、张掌和丢失安全行为。
- React 测试证明第一帧捏合立即发送对应覆盖层状态，左键反馈不依赖 350ms 拖动阈值，并验证右键、双击和滚动桥接调用。
- preload、IPC、控制器和 RobotJS 适配器分别测试有效调用、无效载荷、未授权会话、拖动互斥和动作顺序。
- 覆盖层测试检查所有状态样式与点击脉冲消息。
- 最终运行完整 Vitest、Web/TypeScript 构建、Electron 类型检查和 Electron 打包。
- 打包后启动应用做实际运行验收：总开关保持开启，跨应用验证左键、右键、双击、拖动和滚动，并确认圆形光标在动作第一帧切换状态且原生光标仍被隐藏。
